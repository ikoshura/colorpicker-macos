Features

  • Native window, native traffic lights, no Electron and no Node runtime.
  • RGBA sliders, numeric fields and a hex field with one-tap copy.
  • A screen picker with a magnifier loupe that follows the cursor.
  • Shading sets: tints, naturals and shades for the current color.
  • A colorsbook to keep and reuse your own palette.
  • Menu bar integration with the same shortcuts as the original app.

Lightweight

The native macOS app is only 618 KB, compared to 96.6 MB for the original Electron Colorpicker. No Node runtime, no Chromium, just Swift.

Install

Download the latest .dmg from the releases page, open it, and drag Colorpicker into your Applications folder.

Credits

This app is a native rewrite of the original Colorpicker by Toinane, which is still the original developer of the project.
